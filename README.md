# 🌾 Automatic Seed Sowing Machine

## 📌 Overview
Digital control-based system for automated seed sowing at fixed intervals.

## ⚙️ Features
- Timer-based seed dropping
- Embedded implementation
- Verilog-based sequential logic
- Testbench verification with waveform

## 🏗️ Architecture
Clock → Counter → Control Logic → Motor → Seed Drop

## 💻 Tech Used
- Python
- Verilog HDL
- GTKWave

## 🧪 Verification
- Testbench simulation
- VCD waveform analysis

## 🚀 Future Scope
- FPGA implementation
- Adjustable sowing intervals
- GPS-based precision farming
